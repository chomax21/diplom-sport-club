# Frontend — информационная система спортивного клуба

Адаптивный SPA-интерфейс для API спортивного клуба.

## Стек

- Vue 3 + TypeScript + Vite
- Vue Router, Pinia
- TanStack Query (`@tanstack/vue-query`)
- Axios
- Tailwind CSS 4 + Headless UI Vue
- VeeValidate + Zod
- Chart.js + vue-chartjs
- Vitest + Vue Testing Library
- Playwright для проверки адаптивности и сценариев

## Запуск

```bash
npm install
cp .env.example .env   # при необходимости измените VITE_API_URL
npm run dev
```

Приложение откроется на http://localhost:5173. По умолчанию API доступен на
`http://localhost:8000/api/v1`; если `.env` не создан, используется это же
значение.

- История платежей с фильтрами, детали операции и возврат с отменой абонемента.

## Расписание

Раздел доступен по адресу http://localhost:5173/app/schedule, детальная
страница — `/app/schedule/:id`. Данные загружаются через TanStack Query:

- `sessions` — список и детали тренировок;
- `enrollments` — мои записи и записи на тренировку;
- `rooms`, `trainers`, `clients` — справочники для фильтров и форм.

Запросы выполняются только при активной сессии. После записи, отмены или
отметки посещения инвалидируются связанные ключи, поэтому карточки и
счётчики мест обновляются автоматически. Даты и время вводятся локально,
а на сервер отправляются в ISO 8601 с часовым поясом. Ответы 409 выводятся
рядом с формой или действием: занятость тренера/зала, отсутствие абонемента,
переполненная группа и другие бизнес-конфликты.

## UI-кит

Компоненты находятся в `src/components/ui`, экспортируются из
`src/components/ui/index.ts`. Реализованы `AppButton`, `IconButton`,
`AppInput`, `AppTextarea`, `AppSelect`, `AppCheckbox`, `AppSwitch`,
`DatePicker`, `DateRangePicker`, `AppModal`, `AppDrawer`, `ConfirmDialog`,
`DataTable`, `AppPagination`, `SearchInput`, `FilterBar`, `AppBadge`,
`StatusBadge`, `AppAvatar`, `AppTooltip`, `EmptyState`, `ErrorState`,
`LoadingState` и `SkeletonBlock`.

`DataTable` показывает таблицу от 768 px и карточки на меньшей ширине.
`AppModal` и `AppDrawer` на мобильных занимают весь экран и закрываются по
Escape. Все интерактивные элементы имеют touch-зону не меньше 44 px и
видимый focus ring.

Демонстрационная страница доступна администратору по адресу
http://localhost:5173/app/ui-kit. Она загружается отдельным чанком и не
попадает в основную навигацию.

## Доступность и адаптивность

- Поддерживаются ширины 360, 390, 768, 1024 и 1440 px; горизонтального
  скролла нет, таблицы на мобильных превращаются в карточки.
- Skip-link переводит фокус на `main`, после SPA-перехода фокус остаётся
  в основном содержимом.
- `AppModal` и `AppDrawer` блокируют скролл, удерживают фокус, закрываются
  по Escape и возвращают фокус на кнопку-триггер.
- Вкладки отчётов и радиогруппа видов абонемента управляются стрелками,
  Home и End.
- Контраст текста соответствует WCAG 2.1/2.2 AA, статусы передаются
  текстом и цветом одновременно.
- При `prefers-reduced-motion` анимации, переходы и плавный скролл
  отключаются.
- Аудит: axe-core — 0 нарушений, Lighthouse accessibility — 100 для
  `/login`, `/app` и `/app/reports`; 25/25 сценариев клавиатуры и фокуса
  проходят в Playwright. Текст, увеличенный до 200 %, не создаёт
  горизонтального скролла.

```text
├── views/          # landing, вход, панель, расписание и UI-кит
├── assets/         # глобальные стили и дизайн-токены
└── main.ts
```
